# 🎓 NTU DCS Academic Compass (Batch 2025–29)

**NTU DCS Academic Compass** is an advanced academic planner and AI-powered advisor web app built specifically for National Textile University (NTU) Department of Computer Science students (**BS AI**, **BS CS**, and **BS SE**).

## ✨ Key Features
- 📚 **Multi-Degree Support:** Official Scheme of Study for BS AI, BS CS, and BS SE (Batch 2025–29).
- ⚖️ **Dual Grading Modes:** Letter Grade Selector & Marks Percentage (%) Mode with auto-mapping.
- 🎯 **Target CGPA Predictor:** Instant calculations for required future GPA to hit target CGPA.
- 🤖 **Compass AI Advisor:** Powered by **Groq (Llama-3.3-70B)** for real-time personalized academic guidance.
- 📊 **Visual Analytics Curve:** Semester-by-semester CGPA progression chart.
- 📄 **Export PDF Summary:** One-click clean academic summary report generator.
